# CORTEX BRIDGE

Лендинг аутсорсинга линейного персонала: вахта в России для граждан
Казахстана и Кыргызстана.

Сайт собран как статические файлы и публикуется через GitHub Pages
из ветки `main` (каталог `/`).

- `index.html` — страница
- `assets/style.css`, `assets/index.js` — стили и логика
- `img/` — фотографии и фавиконка

Открывается без сервера: сборка рассчитана на протокол `file://`.
